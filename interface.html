Interfaces para POPStarter

POPSLoader

O POPSloader é uma Interface exclusiva para o POPStarter. Foi criado por NathanNeurotic e suporta o BDMAssault. É compativel com pen drive, MX4SIO, MMCE, HDD (BDMAssault) e CD (DKWDRV)

OSD-XMB

O OSD-XMB foi ciado pelo HiroTex para imitar a interface do Playstation Portatil e do Playstation 3. Também é compativel com o Neutrino, o que demonstra sua versatilidade com jogos de PS1 e de PS2

RETROLauncher

O RETROLauncher foi criado pelo Spaghetticode com uma estética vaporave, que imita os anos 80. Também é compativel com RetroArch, o que é um pacote completo
